# Selenium Java Test Automation

## Project Overview

This project contains automated UI tests for the Rahul Shetty Academy Client Demo application. It focuses on login, registration, and dashboard functionality using Java and Selenium WebDriver.

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Git and GitHub

## Testing Scope

- Login and registration functionality
- Dashboard functionality
- Positive and negative test scenarios
- Form validation
- Data-driven testing with TestNG DataProvider
- Product search, filtering, and cart functionality
- Authentication and session behavior
- Page Object Model implementation

## Test Management

Test scenarios and test cases are managed using Jira and Zephyr. Test executions and identified defects are documented as part of the QA workflow.

## How to Run

1. Install a compatible JDK.
2. Open the project in IntelliJ IDEA.
3. Import or reload the project as a Maven project.
4. Allow Maven to resolve the project dependencies.
5. Run `AutomationTest.java` or the configured TestNG test suite.

## Application Under Test

Rahul Shetty Academy Client Demo

**Note:** This is a portfolio project created to demonstrate QA testing and automation skills using a demo application.

## Project Status

This project is a work in progress. Some planned test cases have not yet been automated. Additional test scenarios, improved test coverage, and enhancements to the automation framework are planned for future updates.
